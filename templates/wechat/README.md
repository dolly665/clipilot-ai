# 公众号排版规范

从用户 2026-11-27 给的 4 篇参考文章里提炼，代码在 `src/domain/wechat/`，效果对比看 `preview.html`（浏览器直接打开）。

| 主题 | id | 来源风格 | 适合 |
|---|---|---|---|
| 资讯速报 | `brief` | 科技媒体每日早报 | 新闻汇总、一篇里好几条独立短讯 |
| 深度访谈 | `interview` | 科普媒体访谈稿 | 访谈、问答、深度报道、知识科普 |
| 心得长文 | `essay`（默认） | 个人 AI 博主长文 | 个人观点、经验分享、「N 条心得」清单体 |
| 碎碎念 | `chat` | 个人随笔、社群更新 | 聊天口吻的随笔、近况更新、社群通知 |

## 各主题的组件

**资讯速报**：正文 16px、行高 1.75、字距 1px、两端对齐、段距 25px、纯黑字。小标题 18px 加粗，青绿色荧光底 `#1DE8DD`（换行时每行都有底色）。金句加粗，左边一条青绿竖线。导语和文末 14px 灰 `#888`，文末上方有细分隔线。

**深度访谈**：正文 16px、行高 1.75em、深灰 `#3F3F3F`、左右各缩 8px、段距 24px。导语放在 2px 青灰虚线框 `#9CC9C7` 里，14px 蓝字 `#007AAA`。小标题上方一条渐变线（左半浅蓝 `#B8DDFF`、右半浅青 `#9AE9D2`），下面 16px 居中蓝色粗体。金句是浅蓝底 `#EEF4FC` 圆角卡片（左上角不圆），蓝色粗体。访谈里「提问：」「某某：」这种说话人前缀用 `**加粗**`。

**心得长文**：正文 16px、行高 1.6、左右缩 8px、段距 24px，没有多余装饰，一段一两句。小标题 18px 黑底白字，自动编号「1、」「2、」。金句单独一段，17px 加粗。文末一段加粗的三连引导，再加 12px 浅灰 `#B2B2B2` 署名。

**碎碎念**：正文 16px、行高 1.75、字距 1px，段距很小（4px），像聊天一句接一句。小标题加粗加下划线，可以带「1.」这样的序号。重点和金句用玫红 `#AB1942` 加粗。旁白、吐槽用 14px 灰色居中小字（导语和文末也是这个样式）。

## 通用规则

- 只用行内样式（`style=""`）。公众号编辑器会删掉 `<style>`、class 和外链 CSS。
- 原文一个字不改：只加小标题、挑金句、给少量句子加粗。加粗一段最多一处，全文控制在 5 处左右。
- 小标题 4–12 个字，概括下面那一节；金句必须是原文里的原句。
- 图片的位置用户在公众号后台自己插。
