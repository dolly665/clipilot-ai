# 公众号排版规范

从用户 2026-11-27 给的 4 篇参考文章里提炼，代码在 `src/domain/wechat/`，效果对比看 `preview.html`（浏览器直接打开）。

| 主题 | id | 来源风格 | 适合 |
|---|---|---|---|
| 资讯速报 | `brief` | 科技媒体每日早报 | 新闻汇总、一篇里好几条独立短讯 |
| 深度访谈 | `interview` | 科普媒体访谈稿 | 访谈、问答、深度报道、知识科普 |
| 心得长文 | `essay`（默认） | 个人 AI 博主长文 | 个人观点、经验分享、「N 条心得」清单体 |
| 碎碎念 | `chat` | 个人随笔、社群更新 | 聊天口吻的随笔、近况更新、社群通知 |

## 配色：侘寂风（2026-11-27 用户要求，替换参考文章的原配色）

不用纯黑、不用高饱和色，全部取自然材质：

| 名字 | 色值 | 用在 |
|---|---|---|
| 暖墨 | `#3E3A35` | 正文 |
| 深墨 | `#2F2B27` | 标题、加粗、心得长文的小标题底 |
| 石灰 | `#9A958E` | 导语、旁白、文末 |
| 宣纸 | `#F4F0E8` | 金句卡片底、小标题字 |
| 苔绿 / 淡苔 | `#7C8A6E` / `#E6E9DD` | 资讯速报 |
| 茶褐 | `#8C7B68` | 心得长文金句、深度访谈金句 |
| 赭石 | `#9C6B52` | 碎碎念重点 |
| 青灰 | `#5F7470` | 深度访谈 |
| 细线 | `#DCD5C9` | 分隔线 |

## 各主题的组件（版式保留参考文章，颜色按上表）

**资讯速报**：正文 16px、行高 1.85、字距 1px、两端对齐、段距 24px。小标题 17px 加粗，淡苔底 + 左边 3px 苔绿竖线。金句苔绿加粗，左边一条细竖线。

**深度访谈**：正文 16px、行高 1.85、左右缩 8px、段距 24px。导语放在 1px 苔绿虚线框里，青灰字。小标题上方一条渐变线（左淡苔、右沙色），下面居中青灰粗体，字距 2px。金句是宣纸底圆角卡片，茶褐粗体。说话人前缀用 `**加粗**`。

**心得长文**（默认）：正文 16px、行高 1.8、左右缩 8px、段距 24px。小标题深墨底、宣纸色字，自动编号「1、」。金句单独一段，17px 茶褐粗体。

**碎碎念**：正文 16px、行高 1.8、字距 1px、段距 6px。小标题加粗，下面一条赭石细线。重点和金句用赭石色。导语灰色居中小字。

**文末（所有主题）**：一截 32px 细线，下面居中 14px 小字、字距 2px。默认文案（`DEFAULT_WECHAT_FOOTER`）：

> 我是允安
> 愿你被温柔以待，也能自在生长
> 喜欢的话，点个「在看」，我们下次见

## 通用规则

- 只用行内样式（`style=""`）。公众号编辑器会删掉 `<style>`、class 和外链 CSS。
- 原文一个字不改：只加小标题、挑金句、给少量句子加粗。加粗一段最多一处，全文控制在 5 处左右。
- 小标题 4–12 个字，概括下面那一节；金句必须是原文里的原句。
- 图片的位置用户在公众号后台自己插。
