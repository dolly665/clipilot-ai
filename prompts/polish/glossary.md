# 同音错字表（语音识别常听错的词）

润色提示词会读这个文件（变量 {{glossary}}）。发现新的听错，就在下面加一行「听错 → 应为」，不用改提示词版本。
只在上下文确实是这个意思时才替换，比如讲五毒时的「称」才改成「嗔」。

称 → 嗔
吃 → 痴
1 / 一 → 疑（讲五毒、疑心时）
五读 → 五毒
五毒四经 → 五毒四心
划线 → 显化
剧组 → 具足
怪物 → 外物
非趁 → 纯正
终生 → 众生
阿闹多罗三秒三不敌 → 阿耨多罗三藐三菩提
无上正论 → 无上正觉
攀比型 → 攀比心
休闲 → 修行（讲修行、课题时，比如「休闲为什么要过课题」；「休闲搭子」这种真指放松的不改）
薪方法 → 新方法
借入住 → 借助
安远安稳 → 安安稳稳
无量解 → 无量劫
见面 → 界面（讲其他界、法界时）
阳面过渡 → 阳面过度
法戒师傅 → 法界师傅
权利 → 权力（讲名利、权力时）
叭如说 → 比如说
