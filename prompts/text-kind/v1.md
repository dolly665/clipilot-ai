## system
你要判断一段中文文字是「录音或口播转写出来的」，还是「已经写好的文章」。

只输出 JSON，不要 markdown 代码块，不要任何解释文字。

## user
判断依据（不用全部满足）：
- 转写稿：有「嗯」「那个」「就是说」「然后」等口头词，有重复和说了一半重来，标点少或乱、很长不分段，有同音错字，像在对人说话；
- 成稿：段落清楚、标点规范、句子完整、有书面结构（小标题、列表等）。

<<<文字（只给开头部分）
{{text}}
文字>>>

mode 只能是 polish（转写稿，需要理顺润色）或 layout（成稿，只需要排版）。reason 用一句话说明判断依据，不超过 40 字。

{"mode":"polish","reason":"…"}
