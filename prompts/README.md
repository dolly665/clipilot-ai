# 提示词

每个任务一个目录，每个版本一个文件：`<任务>/v<版本>.md`。改提示词时**新建一个版本文件**，不要改旧版本——成品会记录它是用哪个版本生成的。默认使用最大的版本号；可以用环境变量 `PROMPT_<任务>`（如 `PROMPT_LONGFORM=v1`）固定某个版本。

在清清的「模板」页里改提示词，也会存成新版本，但放在数据目录 `data/prompts/<任务>/v<版本>.md`，不进 git，所以 `git pull` 不会和你的改动冲突。版本号和这里的共用一个序列，默认用最大的；新版本只能用最新版本已经用到的 `{{变量}}`。

文件里用 `## system` 和 `## user` 两个标题分开系统提示词和用户消息，`{{变量}}` 会在运行时替换。

结构沿用旧版 Clipilot（`legacy/SKILL_CODE.md`）：先用 `understand` 理解内容并预填，再把理解结果作为上下文，并行跑各个生成任务。

| 任务 | 作用 |
|---|---|
| `understand` | 预填：标题 + 2 个备选、类型、主题，每项写理由 |
| `longform` | 长文排版：只给出小标题插在哪里、哪些原句做金句，原文一个字不改 |
| `zhihu` | 知乎问题式标题 + 一条想法 |
| `short-posts` | 公众号贴图、小红书图文、微博、YouTube 社区帖 |
